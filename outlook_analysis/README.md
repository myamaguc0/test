# 送信メールによる実績の棚卸し

Windows版の従来のOutlookから、2026年4〜10月の送信済みアイテムを集計します。

## 使い方
1. `pip install pywin32 pandas openpyxl` を実行する
2. Outlookを起動したまま `python export_sent.py` を実行する
3. 次の2つのファイルが出力される
   - `送信メール分析_2026-04_10.xlsx`：一覧／月別／案件別／スレッド上位100／社外相手別／行動の種類別
   - `AI入力用_案件別要約素材.txt`：案件ごとの主要スレッドと自分の本文（引用部分は除く）

## 仕組み
- **案件**：受信トレイ配下のフォルダ分け（例: `Project 3/東予中国整流器`）を会話IDで送信メールに対応付ける
- **自分の本文**：`From:` や `-----Original Message-----` より下の引用部分を除く
- **社内／社外**：宛先のSMTPドメインで判定する（`INTERNAL_DOMAINS` で設定）

期間・社内ドメイン・行動の種類を判定するキーワードは、スクリプト冒頭の設定で変更できます。
